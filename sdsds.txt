Required product behavior:
- The assistant must feel calm, trustworthy, psychologically safe, and supportive at all times.
- The assistant must be accurate, practical, culturally relevant, and concise.
- The assistant must never hallucinate facts; if uncertain, it should say so and recommend local agricultural extension guidance when appropriate.
- The assistant must detect when the user is writing in Bengali or English and reply in the same language by default.
- The assistant must generate a short conversation title from the first meaningful user message.
- The assistant must include 2 to 4 brief follow-up suggestions after each answer when helpful.

Conversation and message persistence:
- Store conversations in a database and load them by conversation ID.
- Store messages in a database and load the full message history when a conversation opens.
- Support conversation creation, rename, delete, pin, unpin, archive, unarchive, and shared read-only access.
- Keep unread, active, and timestamp states visible where useful.
- Support streaming assistant responses so the UI can render incremental updates.

Authentication and access control:
- Require login for the main chat experience.
- Redirect unauthenticated users to the login page.
- Allow public access only to shared read-only conversation pages when sharing is enabled.
- Enforce ownership checks for all private data including conversations, messages, and memory entries.
- Apply safe rate limiting to prevent abuse.


Memory and personalization:
- Store private per-user memory entries such as preferences, farm facts, crops, locations, and recurring issues.
- Provide UI and API support to list, add, delete, and clear memory entries.
- Inject relevant memory into assistant prompts when helpful.
- Support manual memory entry from the UI.
- Make memory private to the logged-in user.

Voice features:

Sharing:

# Assistant Response Animation & Streaming Experience

The chat experience must clearly communicate when RISA AI is thinking and responding.

## Typing State

Immediately after the user sends a message:

Show a typing indicator before the first streamed token arrives.

Examples:

```text
RISA AI is thinking...
```

or

```text
Preparing a response...
```

### Visual Animation

Use subtle, calming animation only.

Recommended:

```text
● ● ●
```

Animated:

```text
● ○ ○
○ ● ○
○ ○ ●
```

or bouncing dots.

Requirements:

* Smooth
* Slow
* Non-distracting
* Accessible
* Respects reduced-motion settings

Avoid flashy loaders or spinners.

---

## Streaming Response

Responses must stream incrementally from:

```text
https://risa.up.railway.app/chat/stream
```

The user should see text appear naturally instead of waiting for the full response.

Example:

```text
I understand that you're feeling overwhelmed...
```

appears progressively.

---

## Cursor Animation

While streaming:

Show a blinking cursor at the end.

Example:

```text
I understand that you're feeling overwhelmed▌
```

Remove cursor when complete.

---

## Message Completion Animation

When the response finishes:

1. Fade out typing indicator.
2. Stop cursor animation.
3. Reveal actions:

```text
👍 Helpful
👎 Not Helpful
📋 Copy
🔊 Listen
↻ Regenerate
```

4. Show follow-up suggestion chips.

---

## Follow-Up Suggestions Animation

After completion:

Animate suggestions in with a subtle fade-up.

Example:

```text
[ Tell me more ]
[ What caused this? ]
[ Give practical steps ]
```

Delay:

```text
300–500ms
```

after completion.

---

## Thinking Duration Rules

If backend latency exceeds:

```text
2 seconds
```

show:

```text
Still working on a thoughtful response...
```

If exceeds:

```text
8 seconds
```

show:

```text
Thank you for waiting. I'm still processing your message.
```

---

## Voice Response Animation

When text-to-speech is active:

Show:

```text
🔊 Speaking...
```

with subtle waveform animation.

Example:

```text
▁▂▃▄▅▄▃▂▁
```

Do not animate aggressively.

---

## Conversation List Animation

For new conversations:

* Fade in
* Slide up slightly
* Duration: 200ms

For renamed conversations:

* Smooth title transition

For pinned conversations:

* Animate pin icon

For archive/unarchive:

* Smooth collapse/expand

---

## Accessibility

Must support:

* Reduced Motion Mode
* Screen readers
* Keyboard navigation

When reduced motion is enabled:

```text
Disable bouncing
Disable sliding
Disable waveform
Keep only opacity transitions
```
